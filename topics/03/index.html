Конструктор вибіркових курсів
для різних профілів

Як створити цілісну траєкторію з 4–6 курсів — без дублювання, із наступністю та зв’язком із профілем? Пройдіть короткі вправи й створіть власний пакет курсів.

Тема 03 / 03Професійне рішення №3Працює зі смартфона
Крок 1 · Досліджуємо

Траєкторія чи розсип?

Для кожного твердження оберіть «Правда» або «Міф». Після вибору побачите пояснення.

Крок 2 · Визначаємо потреби

Профіль визначає маршрут

Оберіть профіль. Перегляньте приклади курсів за вибором профілю та поза профілем. Це приклади для обговорення, а не обов'язковий перелік.

Крок 3 · Аналізуємо

Наступність, дублювання чи розсип?

Оцініть навчальні траєкторії з плану заняття. Для кожної визначте найточніший висновок.

Крок 4 · Проєктуємо

Мій пакет із 4–6 вибіркових курсів

Створіть маршрут для обраного профілю. Вкажіть формат, ключовий результат, попередні знання й міжпредметну інтеграцію. Порядок курсів — це порядок у траєкторії.
