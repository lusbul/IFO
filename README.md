# IFO — практикум для вчителів інформатики

## Завантаження на GitHub
1. Розпакуйте ZIP на комп’ютері. GitHub сам ZIP не розпаковує.
2. У репозиторії lusbul/IFO: Add file → Upload files. Перетягніть ВМІСТ розпакованої папки: index.html, topics, plan.pdf та інші файли. Не завантажуйте зовнішню папку-обгортку.
3. Commit changes. Наявний кореневий index.html буде замінений; його вправу збережено в topics/06/sprint.html. Інші наявні файли не видаляйте.
4. Якщо Pages ще не налаштовано: Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Структура
index.html — головна сторінка зі вбудованими CSS та JavaScript.
topics/01/ … topics/16/ — окремі папки тем.
topics/06/sprint.html — попередня головна IFO, збережена як вправа.
topics/07/constructor.html — новий конструктор завдання.
plan.pdf — вихідний тематичний план.

## Як додати наступне завдання
Покладіть HTML у папку відповідної теми, наприклад topics/07/task-02.html. Додайте посилання на нього у topics/07/index.html і в картку теми на головній index.html. CSS та JS нових завдань можна вбудовувати в їхній HTML. Для зовнішніх репозиторіїв використовуйте повну адресу GitHub Pages.

Пошук охоплює назви тем та описи завдань. Фільтр модулів поєднується з пошуком і перемикачем готових завдань. Прогрес та чернетка зберігаються локально, без сервера. Місця для майбутніх завдань позначено явно, вигаданих вправ і порожніх активних кнопок немає.
